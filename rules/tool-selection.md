# Tool Selection Priority [MUST]

操作前先评估：是否有现成工具/Skill 可以完成？选择 token 消耗最小的方案。

## 1. 搜索与查找

| 优先级 | 工具 | 适用场景 | Token |
|--------|------|---------|-------|
| 1 | Grep | 已知符号/字符串搜索 | 低 |
| 2 | Glob | 已知文件名模式 | 低 |
| 3 | Read (offset+limit) | 读取已知文件的特定行 | 中 |
| 4 | Agent (Explore) | 宽泛不确定性搜索 | 高 |
| 5 | WebSearch | 外部信息查询 | 极高 |

## 2. 修改文件

| 优先级 | 工具 | 适用场景 | Token |
|--------|------|---------|-------|
| 1 | Edit | 精确字符串替换（≤20 行） | 低 |
| 2 | Write | 新建文件或完全重写 | 中 |
| 3 | Bash(sed/awk) | 批量正则替换 | 中 |

## 3. 执行复杂任务

| 优先级 | 工具 | 适用场景 | Token |
|--------|------|---------|-------|
| 1 | 直接执行 | 简单改动（单文件/≤30 行） | 低 |
| 2 | EnterPlanMode | 复杂改动先出方案 | 中 |
| 3 | Agent (Plan) | 需要独立设计的多文件实现 | 高 |

## 4. 规则

- Agent (Explore) 仅用于需要跨多个目录/多轮搜索的探索
- Agent (Plan) 仅用于复杂多文件任务，简单改动直接动手
- Agent (general-purpose) 仅在 Explore/Plan 都不适用时使用
- WebSearch/WebFetch 仅在用户明确要求或本地信息确实不足时使用
- Skill 优先于 Agent——检查是否有匹配的 skill，没有再考虑 Agent
